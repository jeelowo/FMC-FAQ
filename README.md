# FAQ Accordion

A responsive FAQ accordion built as a solution to the [Frontend Mentor FAQ accordion challenge](https://www.frontendmentor.io/challenges/faq-accordion-wyfFq7k6Bz).

## Overview

This page presents frequently asked questions in a compact accordion layout. Users can select a question to show or hide its answer, with the control icon changing between plus and minus states.

### Features

- Responsive layout for mobile and desktop screen sizes
- Interactive expand and collapse controls
- Accessible button controls with changing alternative text
- Frontend Mentor challenge attribution

## Built With

- Semantic HTML5
- CSS3
- Vanilla JavaScript
- [Work Sans](https://fonts.google.com/specimen/Work+Sans) from Google Fonts

## Getting Started

This is a static site and does not require a build tool or package installation.

1. Clone or download this repository.
2. Open `index.html` in a browser.

For the best local development experience, serve the project with a local web server, such as the VS Code Live Server extension.
